# 正式实验后的结果填入说明

本文件把无需实验数据的写作准备固定下来。正式研究报告仍使用 [主报告](research_report_draft.md)，展示草稿见 [10 页 PowerPoint](presentation/EP6203-progress-draft.pptx)。禁止把 null、Pending 或未执行写成 0，禁止用校准和 mock 填正式结果。

| 作业结果项 | 可用生成入口／字段 | 写入位置及判读 |
|---|---|---|
| 搜索曲线 | `evaluation.live_report` 的审计重建曲线；`scripts/plot_live.py` | 报告结果节、展示第 6 页。三个搜索方法、Default 参考，美元横轴，只画共同已观测区间 |
| 最终 pass@1 | `methods.*.heldout_pass_at_1`、固定 `heldout_denominator=8` | 第 7 页。成功数/8 与验证分列；任务未执行或计量不完整时结果未知 |
| 泛化差距 | `methods.*.gap_percentage_points` | 第 7 页。同一冻结配置的验证成功率减留出成功率，以百分点表示 |
| 成本权衡 | `optimization_search_usd`、`heldout_runtime_per_task_usd` | 第 8 页。Default 搜索成本为 0，但其验证测量费用单列；历史校准与新实验分账 |
| 参数敏感性 | `sensitivity`、配置覆盖、匹配局部对照 | 第 8 页。缺四角/背景不一致写不可识别；v8 不执行 pair-blind，不能报告其成绩或声称引导独立收益 |
| 双向失败案例 | `paired_heldout`、`failure_cases`、官方 verifier、脱敏轨迹 | 第 9 页。分别报告调优赢/默认赢；若某方向为空直接说明，不挑其他配置补案例 |

## 结果生成顺序

按 [交接手册](reproduction_handoff.md) 完成审计、统一冻结、留出后生成 `evaluation.live_report`，再绘图。报告工具拒绝 mock、校准或 fixture 冒充真实研究。正式文件必须附协议哈希、source pins、种子、冻结身份和完整性状态。

## 预先确定的结论写法

- 有观察到的提升：报告准确任务数、成本、分母和差值，并写明单种子、8 题与供应商随机性；不声称显著或普遍优越。
- 未观察到提升：如实报告各方法结果，分析初始化成本、参数是否触发、局部对照覆盖和任务异质性。
- 未完成：保留已消耗费用、失败及未知计量；不能选择性删题、缩小分母或宣布赢家。

## 展示与 Q&A

草稿 10 页配有中文讲稿与来源，建议用时依次为 40、60、80、70、50、60、65、65、60、50 秒，合计 600 秒，另留 5 分钟 Q&A。实际计时演练、正式图表排版和结论更新依赖真实结果，不能预先勾选完成。

实验后最终核对：四方法齐全；验证/留出隔离；六类结果齐全或明确无法识别；图表与 JSON 一致；敏感信息不外发；报告和展示没有将工程证据写成优化效果。原始日志保留本地，公开结果另作字段审阅。
