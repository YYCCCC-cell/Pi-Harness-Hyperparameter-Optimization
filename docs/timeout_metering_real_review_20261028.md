## 发现、修复与证据边界

最初的自动结果保留为 `measurement_incomplete`，不覆盖。原因是 LiteLLM 的 Responses→Chat 转换在中间片段生成了 8,164 个 `chatcmpl-UUID` 临时 ID；旧审计将其当作无效供应商 ID。这 21 个请求事实上都已经正常完成，而且自动对账阶段已取得全部 generation 回执。

修复后，审计只忽略严格匹配 UUID 形式的代理占位 ID，仍要求每个请求恰好关联一个真实供应商 ID；缺失 ID、多个真实 ID、重复 handoff、未结算或非法回执仍会阻止结算。用未修改的封存日志与已有 21 个回执重算，侧车审计完整通过；只再读取一次账户用量，没有重复请求 generation 或新建模型调用。

此外，独立源码复核发现转换会丢掉 `response.created` 中的早期供应商 ID。新增项目适配层，在转换之前通过上游迭代器的稳定 call ID 持久化 response ID；不修改第三方文件，也不改变返回给 agent 的内容。新增本地测试覆盖真实安装的转换器，以及真实 LiteLLM 代理的 `/chat/completions`→`/responses` 转换、首个事件后断开场景。没有最终回执时费用仍为未知。

**这些后续修复尚未再运行付费任务。** 本地测试验证的是软件路径；此次真实任务只验证了完整请求的费用、用量和耗时。不能把“本地取消测试通过”写成“真实 OpenRouter 超时计费已验证”，也不能借此消除旧自行车任务的历史未知费用。

代码入口：

- `evaluation/timeout_diagnostic.py`：独立单次诊断、原预算与已对账余额核验、持久化一次性 claim；崩溃不自动重试。
- `evaluation/diagnostic_spend_guard.py`：按最新目录每次请求预留 $0.876 的全输入/全输出费用包络；完成后按未缓存费率和供应商用量中的较高值记账，未知请求保留预留。拒绝不在 token 包络内的付费原生工具。它是本地价格保护，不是供应商硬额度。
- `evaluation/request_accounting.py`、`provider_callback.py`：处理代理占位 ID，保持未知费用停止规则。
- `evaluation/response_bridge_observer.py`：转换前捕获 ID；关联信息缺失时停止，不猜测所属请求。
- `scripts/reconcile_timeout_diagnostic.py`、`review_real_timeout_budget.py`：只读回执复核和可重算预算方案。

## 正式规模与预算复核

为估算未来任务费用，将 7 个历史可完整计量任务与本次自行车观测组成一轮 8 任务的规划样本，合计 **$1.00977450、3,046.687576 秒**。这只替换未来成本估算中的自行车样本，不删除旧失败尝试、不退款、不结清旧未知账单。它混合了前后两种计量/传输版本，每任务仅一个样本，不能视作统计置信区间。

|---|---:|---:|---:|---:|---:|---:|
| 保留现有范围 | 8 / 16 | 504 | $63.62 | **$131.27** | **$155** | 53.3–106.6 小时 |
| 较省预算的探索范围 | 4 / 8 | 252 | $31.81 | **$65.64** | **$80** | 26.7–53.3 小时 |

每个搜索方法保留 13 配置：IGBS 的 7 个初始配置 + 6 次自适应选择，两轮三步循环。四种搜索是 Random、BO、IGBS、pair-blind，另加 Default；只有一个搜索种子。若费用整体为均价的三倍，两种范围分别约 $190.85 / $95.42，说明派发额度不能保证跑完全部尝试。

$155 分配为 Default $5、每种搜索 $30、独立留出 $30；$80 分配为 Default $5、每种搜索 $15、独立留出 $15。两者均未获正式执行授权。这里的倍率及额度是规划假设，不是实测上限，也不含硬件、电费或其他本地成本。

预算优先时，建议把 **252 次 / $80** 作为下一版探索性方案的候选；它牺牲任务覆盖和结论稳定性，不能承诺 IGBS 优势。当前仅 8/16 的清单已冻结并通过任务/家族无交叉检查。4/8 仍需按任务元数据、与成绩无关地选取，建立新的划分与代码快照。不得直接把现有入口的任务数量改小后执行。

正式执行仍遵循：验证集搜索 → 冻结配置 → 独立留出；各方法预算和任务条件一致。启动前还需完成真实受控超时的计量验收、确认所选范围及具体额度，并更新计量修复后的协议来源哈希。**本轮不继续付费重试，也不启动正式实验。**
