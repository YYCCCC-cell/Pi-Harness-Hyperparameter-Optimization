A package version string does not establish equality with a published release artifact. Current [Pi settings](https://pi.dev/docs/latest/settings) and [configuration](https://pi.dev/docs/latest/configuration) pages were also accessed; the table's authoritative domains and defaults remain tied to the immutable checkout.

All 72 named setting rows from the pinned settings reference are included. ## Explicit exclusions and implementation checks

- No universal `temperature`, `top_p`, `seed`, `maxTurns`, `max_steps`, `tool_timeout`, or task-wide dollar-budget key is documented in this pinned `settings.json` schema. A tool-call argument, an adapter control, and a Pi configuration parameter are different interfaces. Do not infer a knob from the assignment's examples.
- In current Harbor, `max_turns` generates an extension that adds a prompt instruction and aborts on turn count. It is not a native Pi setting; leave it unset for this strict configuration-only study. [Harbor extension implementation](https://github.com/harbor-framework/harbor/blob/6099b8cf2bfbbb3e7ff1eb2163bfc4524dbd9ba5/src/harbor/agents/installed/pi.py#L369-L403)
